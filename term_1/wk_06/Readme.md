# Неделя 6

Примеры к задаче [wk_05](../wk_05/Readme.md): симулятор математического маятника на C++
(явная схема Эйлера), который получает параметры из JSON-файла и запускается из Python.
Схемы Хойна, Рунге-Кутты и неявный Эйлер в примере **не** реализованы: в коде отмечены места, куда их добавлять.

Описание, установка, запуск и отладка в VS Code: [examples/README.md](examples/README.md).
